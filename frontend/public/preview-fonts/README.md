# Preview fonts

These fonts serve only the standalone design studio, not the production theme.

- Switzer Regular / Semibold: unmodified copies of the existing landing assets, copyright Indian Type Foundry. [Family](https://www.fontshare.com/fonts/switzer), [ITF Free Font License](https://www.fontshare.com/licenses/itf-ffl).
- Fraunces Latin 500 normal: Fontsource `@fontsource/fraunces@5.2.7`, static WOFF2; see `fraunces-LICENSE.txt`.
- Instrument Serif Latin 400 normal: Fontsource `@fontsource/instrument-serif@5.2.6`, static WOFF2; see `instrument-serif-LICENSE.txt`.

Both serif files were obtained from the version-pinned Fontsource packages via jsDelivr. All four fonts are served locally; switching does not require a third-party font request.
