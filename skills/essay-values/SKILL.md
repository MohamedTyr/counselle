# Essay Values

Source: adapted from *College Essay Essentials* (Ethan Sawyer). Load
`essay-honesty` first — value-naming is interior work and the propose/assert
line applies. Values are the unit of meaning in essay work: an anecdote
matters because of the value it reveals. This skill is the bank plus the
judgment rules; the interviews that use it live in `essay-brainstorm`, the
craft moves in `essay-craft`.

## The funnel

Top ten → top five → top three → the single most important value *today*. The
"today" framing is load-bearing: it lowers the stakes of choosing and makes the
answer honest. The follow-up — "why is that one first?" — is where the essay
material is. Do the funnel with the student turn by turn; never run it for them.

## The predictable-values rule

Some values are what nearly every applicant claims: hard work, perseverance,
dedication, determination, passion, leadership. They are not forbidden — they
are *expensive*. The real rule: **the more common the value, the stronger and
more specific the insight attached to it must be.** "I learned the value of
hard work" purchased with a sports anecdote reads as filler; the same value
earned through a surprising, particular realization can still land. When a
draft leans on a predictable value, either deepen the "so what" (load
`essay-depth`) or surface the *less* usual value hiding underneath (healthy
boundaries, inheritance, craft, risk…). Unusual values get no free pass on
delivery either: never announced bluntly — show how the value developed, then
explain its significance.

## The guess test

The selection procedure for a value worth ending on: imagine the student has
just described the challenge and what they did, and is about to name what
they gained. *Could a listener guess that value before it's said?* Immigrant
story → resilience; captain story → leadership; injury story → perseverance.
**If guessable, pick a different value and test again — repeat until the
listener couldn't have guessed it.** That's the default loop. The one
exception is the caveat above: a guessable value may stay only when its
so-what is genuinely exceptional — and that's the harder road, so say so.
The un-guessable value beside the obvious one is where a familiar topic
becomes a personal essay.

## Values and careers

A career is never the end goal; it is the means by which a person experiences
and expresses their values. So "why medicine?" is really "which of your values
does medicine let you live?" — and a student's values *are* their dreams and
aspirations. Two uses:

- **Amazing-[career] exercise:** ask the student which ~5 values a truly great
  person in that career embodies, then which of those they already hold and
  where each shows up in their life. Overlaps are essay material; gaps are
  growth material (also legitimate essay material).
- **Ending audit:** a career-mention in an ending should read as
  values-expression, not trophy-claiming — check which named value it pays off.

## Value density (audit move)

Strong essays reveal several *distinct* values in a short span — the best
paragraphs show four or five different values in a few dozen words without
naming any of them. When auditing a draft, mark each anecdote with the values
it actually demonstrates (shown, not claimed). One value repeated five times
reads thin; a spread of distinct values reads like a person. Report the audit
as an observation with evidence ("this paragraph shows X and Y; nothing yet
shows a third"), and let the student decide what to add — additions are their
material, gathered by interview.

## Traps

- **Assigning a value is fabrication.** "You clearly value independence" is an
  assertion about a person's interior; offer it as a candidate reading of what
  they wrote and ask.
- **Claimed ≠ shown.** A sentence that names a value ("I value honesty")
  demonstrates nothing; only an anecdote demonstrates. Flag claims without
  evidence during audits.
- **Don't flatten to one value.** Funnel picks a #1 for focus, but the essay
  itself usually carries several; forcing everything under one label loses the
  density that makes essays feel human.

## Handoffs

Naming values from scratch → `essay-brainstorm` runs the interview. Deepening a
predictable value → `essay-depth`. Showing a value in prose without claiming it
→ `essay-craft`.
