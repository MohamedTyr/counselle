# Field-category map (1093 fields, 17 categories)

Always-in-context map of the catalog: each category, its size, and a few notable keys (`category.name`, pasteable). Deliberately not exhaustive — use `search_fields` for the long tail.

- **admissions** (185 fields): Test ranges, admit/yield, requirements, CDS: C7 factor weights, test policy, GPA dist, HS rank, ED/EA dates, waitlist. Notable: admissions.acceptance_rate, admissions.admit_rate_total.
- **aid** (150 fields): Net price by income band, grants/loans, debt, repayment, CDS: % need met, CSS Profile flag. Notable: aid.avg_net_price_title4, aid.avg_net_price_0_30k.
- **outcomes** (120 fields): Grad/completion/retention/default rates. Notable: outcomes.grad_rate_6yr_bach, outcomes.completion_150_4yr.
- **programs** (107 fields): CIP degree-offered flags, degree counts. Notable: programs.offers_cs_bachelors, programs.offers_engineering_bachelors.
- **cost** (92 fields): Tuition/fees/room&board, net price. Notable: cost.tuition_in_state, cost.tuition_out_of_state.
- **institution** (77 fields): Identity, Carnegie, HBCU/HSI, locale, URLs, endowment. Notable: institution.hbcu, institution.hispanic_serving.
- **academics** (75 fields): Student-faculty ratio, expenditures, services, CDS: class-size dist, grad requirements. Notable: academics.student_faculty_ratio, academics.instruction_expenditure_per_fte_gasb.
- **enrollment** (73 fields): Headcounts, FTE, FT/PT. Notable: enrollment.total_headcount, enrollment.undergrad_total.
- **demographics** (68 fields): Race/ethnicity, sex, age. Notable: demographics.pct_white_total, demographics.pct_black_total.
- **earnings** (53 fields): Scorecard only. Post-entry/post-completion earnings (lagged). Notable: earnings.median_4yr_postcompletion, earnings.median_6yr.
- **retention** (24 fields): Retention & multi-year persistence. Notable: retention.rate_full_time.
- **student_life** (20 fields): CDS only. On-campus living, Greek life, housing.
- **faculty** (15 fields): CDS only. Class sizes, terminal-degree %, ratio. Notable: cds.pct_class_sections_under_20.
- **transfer** (13 fields): CDS only. Transfer admission detail.
- **students** (10 fields): Scorecard family-income/first-gen/veteran. Notable: students.share_first_gen.
- **completers** (6 fields): IPEDS bachelor's completers by race/sex.
- **general** (5 fields): CDS Section A (control, calendar, DEI URL).
